# Python OOP Assignment

## Description
This project demonstrates the fundamental concepts of Object-Oriented Programming (OOP) in Python through six tasks.

## Tasks Included

### Task 1: Basic Class & Object Creation
- Created a Product class.
- Added attributes: name, price, category.
- Implemented get_info() method.
- Created two product objects.
- Added apply_discount() method.

### Task 2: Constructor & Encapsulation
- Made price a private attribute.
- Implemented getter and setter methods.
- Updated price using the setter.

### Task 3: Inheritance
- Created ElectronicProduct class inheriting from Product.
- Added warranty_years attribute.
- Overrode get_info() method.

### Task 4: Polymorphism
- Created Laptop and Mobile classes.
- Overrode get_info() in both classes.
- Demonstrated polymorphism using a loop.

### Task 5: Abstraction
- Created an abstract Payment class.
- Implemented CreditCardPayment and UPIPayment subclasses.
- Overrode process_payment() method.

### Task 6: Magic Methods & Operator Overloading
- Implemented __str__() for readable object representation.
- Implemented __add__() to add prices of two products.

## Technologies Used
- Python 3
- Object-Oriented Programming (OOP)

## OOP Concepts Covered
- Classes and Objects
- Constructors
- Encapsulation
- Inheritance
- Polymorphism
- Abstraction
- Magic Methods
- Operator Overloading

## How to Run
1. Install Python 3.
2. Save each task in a separate Python (.py) file.
3. Open a terminal in the project folder.
4. Run the desired file using:

   python task1.py
   python task2.py
   python task3.py
   python task4.py
   python task5.py
   python task6.py
