# Exception Handling in Python

## 📌 Assignment Title
**Exception Handling in Python**

## 📖 Description
This assignment demonstrates the use of Python exception handling techniques to make programs more reliable and user-friendly. It includes examples of handling built-in exceptions, creating custom exceptions, and safely managing file operations and user input.

## 🚀 Tasks Included
- **Task 1:** Safe Division Utility
  - Handles `ValueError` and `ZeroDivisionError`.
  - Uses `try-except-else-finally` blocks.

- **Task 2:** Bill Calculator with Error Handling
  - Calculates the total of valid product prices.
  - Skips invalid or negative values using exception handling.

- **Task 3:** Custom Exception – Age Validator
  - Creates a custom exception for invalid age input.
  - Validates that age is between 1 and 120.

- **Task 4:** File Reader with Exception Handling
  - Reads a file safely.
  - Handles `FileNotFoundError` and `PermissionError`.
  - Displays the first three lines of the file.

- **Task 5:** Mini Program – Safe Shopping Cart
  - Accepts product prices until the user enters `q`.
  - Handles invalid and negative inputs.
  - Calculates and displays the final total.
