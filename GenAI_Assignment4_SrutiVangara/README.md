# 📂 Python File Handling Assignment

## 📖 Overview
This repository contains solutions for seven Python File Handling tasks. The tasks cover creating, reading, writing, appending, and safely handling files using Python's built-in file handling functions.

---

## 🚀 Tasks Completed

### ✅ Task 1: Write Sales Records to a File
- Created a list of sales amounts.
- Wrote the sales data into `sales_data.txt`.
- Read and displayed the file contents.

### ✅ Task 2: Read File in Different Ways
- Read the entire file using `read()`.
- Read the first line using `readline()`.
- Read all lines using `readlines()`.
- Converted the file data into integers.

### ✅ Task 3: Append New Sales
- Appended new sales records to the existing file.
- Displayed the updated file.
- Calculated the total number of records.

### ✅ Task 4: Generate Summary Report
- Read sales data from the file.
- Calculated:
  - Total Sales
  - Highest Sale
  - Lowest Sale
  - Average Sale

### ✅ Task 5: Create Product File
- Accepted product names and prices from the user.
- Stored them in `products.txt`.
- Read and displayed the formatted product list.

### ✅ Task 6: Read File Safely
- Asked the user for a filename.
- Checked whether the file exists using `os.path.exists()`.
- Displayed the file contents if found.
- Displayed an error message if the file does not exist.

### ✅ Task 7: Mini Project – Export Discounted Prices
- Created a dictionary of product prices.
- Accepted a discount percentage.
- Calculated discounted prices.
- Saved the report in `discount_report.txt`.
- Displayed the report.
- Included:
  - Total Items
  - Average Discounted Price
