# Pandas Data Analysis Assignment

## 📌 Overview

This assignment demonstrates the fundamental concepts and practical applications of the **Pandas library in Python** for data manipulation, analysis, and visualization.

The assignment consists of a series of Python programs that progressively explore:

- Pandas Series
- Series operations
- Statistical functions
- DataFrame creation and inspection
- Data filtering
- Sorting and indexing
- GroupBy operations
- Data visualization
- Basic sales data analysis

The programs use sample student and sales datasets to demonstrate how Pandas can be used to efficiently process and analyze structured data.

---

## 🎯 Objectives

The main objectives of this assignment are:

1. To understand the fundamentals of the Pandas library.
2. To create and work with Pandas Series.
3. To perform arithmetic operations on Series.
4. To calculate basic statistical measures.
5. To create and manipulate Pandas DataFrames.
6. To inspect and summarize tabular datasets.
7. To filter data based on specific conditions.
8. To sort and reset DataFrame indexes.
9. To perform data aggregation using `groupby()`.
10. To visualize data using Pandas plotting functions.

---

## 🛠️ Technologies Used

- **Python 3**
- **Pandas**
- **Matplotlib** (used internally by Pandas for plotting)
