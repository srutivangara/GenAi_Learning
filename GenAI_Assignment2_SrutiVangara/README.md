# Order Discount Management System

## 📌 Overview
This project is a simple Python program that demonstrates the use of conditional statements, loops, lists, and exception handling. It allows users to calculate order discounts, process multiple orders, and interact with a menu-driven application.

## ✨ Features

### Task 1: Discount Calculator
- Accepts an order amount from the user.
- Applies discounts based on the order amount:
  - 15% discount for orders ≥ 2000
  - 10% discount for orders between 1500 and 1999
  - 7% discount for orders between 1000 and 1499
  - No discount for orders below 1000
- Calculates subtotal after discount.
- Adds 5% tax.
- Displays the final amount.
- Handles invalid (non-numeric) input using exception handling.

### Task 2: Process Multiple Orders
- Processes a predefined list of orders.
- Applies the discount rules to each order.
- Displays:
  - Original order amount
  - Discount applied
  - Final amount
- Calculates total revenue after discounts.
- Counts the number of orders that received a discount.

### Task 3: Menu-Driven Program
- Uses a `while` loop to display a menu.
- Allows users to:
  - Add new order amounts.
  - View all processed orders with discounts.
  - Quit the program.
- Uses `break` to exit and `continue` for invalid menu options.

## Task4: Loop Control with conditions
- uses `for` loop to iterated.
- checks the values in list and perform it's respective functions
