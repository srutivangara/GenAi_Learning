## Overview
This assignment demonstrates the use of functions in Python, including:

User-defined functions

Lambda (anonymous) functions

Higher-order functions such as map(), filter(), and reduce()

The goal is to understand how functions improve code reusability, readability, and efficiency.

## Learning Outcomes
Understand how to define and call functions.

Learn the difference between named functions and lambda functions.

Explore functional programming concepts using map(), filter(), and reduce().

Gain hands-on experience in writing clean, reusable, and efficient code.
